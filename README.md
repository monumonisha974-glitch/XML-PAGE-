# Employee Directory

## Project Description
The Employee Directory is a web-based application designed to display and manage employee information. It loads employee details from an XML file (`employees.xml`) and allows users to search for employees based on their name, department, or city.

## Features
- Displays employee information from an XML file.
- Search employees by name.
- Filter employees by department.
- Search employees by city.
- Supports loading another XML file.
- Simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript
- XML

## Working Procedure
1. Open the Employee Directory website.
2. Employee details are loaded from the `employees.xml` file.
3. Enter an employee's name, department, or city in the search box.
4. The application displays matching employee information.
5. Users can also load another XML file to view different employee records.

## Objective
The main objective of this project is to provide a simple and efficient way to view and search employee information using XML and web technologies.
